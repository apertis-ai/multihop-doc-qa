# Multihop Document QA

Official code and data releases for the Apertis AI multihop document-QA papers.

## Releases

- [Paper 2: A Late-Interaction Retriever Matches Graph-RAG on Multi-Hop Document Retrieval](paper2/) — evaluation data, per-query results, audit artifacts, code, configurations, and checkpoint links.

Compact artifacts live in this repository. Large datasets and adapter weights are hosted on Hugging Face and linked from each release package; RunPod storage is not required for public access.
